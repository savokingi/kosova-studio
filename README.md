# Kosova Studio

Авторский многостраничный сайт студии текстильного дизайна Юлии Косовой.

## Запуск

`npm run dev` — http://127.0.0.1:4173

`npm run build` — генерация страниц из `build.mjs`.

`node check.mjs` — проверка всех локальных ссылок и изображений.

## Содержание и редактирование

`build.mjs`: проекты, услуги, подборки, статьи и HTML-композиции.

`dist/styles.css`: визуальная система и адаптивные стили.

`dist/app.js`: фильтры, поиск, сохранение подборки, галерея, мобильное меню, подготовка обращения.

Фотографии получены из публичных публикаций Kosova Studio; `asset-sources.json` содержит ссылки на оригиналы. В библиотеке представлены редакционные сочетания по мотивам проектов, а не товарные SKU с подтвержденным наличием. Цены и отзывы не выдумывались.

Контактная форма готовит сообщение для отправки самим посетителем в Telegram. Серверного приема заявок и оплаты нет. Подборка сохраняется локально в браузере.

Сайт публикуется с приватным доступом владельца. Перед коммерческим публичным запуском студии следует подтвердить редакцию материалов, использование фотографий, каталог, условия заказа и необходимые документы.
